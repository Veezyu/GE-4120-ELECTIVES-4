# Activity 5: AI Tools

## Activity Description
This activity explored how artificial intelligence tools can support learning, creativity, information processing, and productivity when used thoughtfully and responsibly.

## What Have I Learned?
- I learned that AI tools can help generate ideas, organize information, support writing, and make some tasks more efficient. I also learned that AI outputs need to be reviewed because they may contain errors or information that requires verification.
- One challenge was learning how to give clear instructions and evaluate the usefulness of generated responses. I addressed this by making prompts more specific, checking the results, and revising the output when needed.
- I can use AI as a support tool for brainstorming and learning while maintaining my own judgment and responsibility, especially in academic and nursing-related work. I can improve by developing better prompts and verifying important information with reliable sources.
