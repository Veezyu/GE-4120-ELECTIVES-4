# Activity 3: Social Media Infographics & Project Documentation

## Activity Description
This activity involved communicating information through social media infographics and documenting project work. It emphasized visual communication, concise writing, organization, and presenting information in an engaging format.

## What Have I Learned?
- I learned how to turn information into concise visual content by combining a clear message, readable text, appropriate images, and a balanced layout. I also learned the importance of documenting project details so that the process and output can be understood.
- One challenge was deciding which information to include while keeping the infographic easy to read. I addressed this by identifying the key message, removing unnecessary details, and organizing the remaining content into a clear visual sequence.
- I can use these skills to create health education materials and awareness campaigns in nursing and community settings. I can improve by checking the accuracy of information, considering the intended audience, and making my designs more accessible.
