# Activity 7: Resume Generating

## Activity Description
This activity focused on creating a resume that presents personal information, education, skills, and relevant experiences in a clear and professional format.

## What Have I Learned?
- I learned how to organize resume information and present qualifications in a concise, professional, and readable way. I also learned that the layout should support the content rather than distract from it.
- One challenge was deciding which details were most relevant and how to arrange them effectively. I addressed this by prioritizing important information, using clear section headings, and reviewing the document for consistency and accuracy.
- I can apply this learning when preparing applications for internships, clinical opportunities, and future nursing positions. I can improve my resume by updating it as I gain experience, highlighting relevant skills, and tailoring it to each opportunity.
