# Activity 1: Presentation Design Principles

## Activity Description
This activity focused on the basic principles of effective presentation design, including organizing information, choosing readable fonts and colors, maintaining visual consistency, and using images or graphics to support the message.

## What Have I Learned?
- I learned that a good presentation should be clear, organized, visually consistent, and easy for the audience to follow. I also learned to use colors, typography, spacing, and visuals purposefully instead of adding elements only for decoration.
- One challenge was deciding how to arrange information without making the slides look crowded. I addressed this by prioritizing the main points, grouping related information, and keeping the layout simple.
- In the future, I can apply these principles to academic reports, case presentations, and other professional presentations. I can continue improving by practicing visual hierarchy and asking for feedback on the readability of my slides.
