# Activity 6: Making a Website

## Activity Description
This activity introduced the process of creating a website and arranging content so that visitors can navigate and understand it. It provided an opportunity to explore basic web structure, design, and digital presentation.

## What Have I Learned?
- I learned that a website brings together content, structure, and visual design to provide information in an accessible way. I also became more familiar with how web pages are organized and how links and visual elements help users navigate.
- One challenge was arranging the content so that the page remained clear and easy to use. I worked through this by organizing information into sections, checking the layout, and making adjustments to improve readability and navigation.
- I can apply these skills to create simple portfolios, project pages, or educational websites. I can improve by practicing HTML and CSS, learning more about responsive design, and testing pages on different screen sizes.
